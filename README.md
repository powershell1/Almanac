# Gaia DR4 amortized orbit posteriors

Amortized neural posterior estimation (NPE) of companion orbits from Gaia DR4 epoch astrometry.
A network trained once on simulated Gaia data returns a posterior over (P, e, T_p) in
milliseconds. The nine linear parameters (position, parallax, proper motion, Thiele-Innes
constants) are integrated out analytically. See `CLAUDE.md` for the scope and the plan.

**Status:** Phase 1 code drafted and tested locally on a toy scanning law. No counted runs and
no research results yet.

## Layout

| Path | What |
|---|---|
| `src/gdr4/model/` | Kepler solver, along-scan design matrix, analytic linear marginalisation |
| `src/gdr4/sim/` | priors (single source of truth), noise models, scan geometry, simulator |
| `src/gdr4/data/` | resumable ragged shards; per-CCD epoch-astrometry loader (DR4 / BH3) |
| `src/gdr4/nn/` | transformer encoder, spline flow + von Mises posterior, training loop |
| `src/gdr4/reference/` | brute-force / importance-sampling reference posteriors; kima stub |
| `src/gdr4/eval/` | HPD + TARP coverage, C2ST, period/alias metrics, kill-test decision |
| `scripts/` | CLI entry points; `scripts/figures/` makes every figure |
| `notebooks/kaggle/` | thin notebooks 01–06 (generated by `build_notebooks.py`) |
| `configs/` | `killtest.yaml` (Phase 1), `smoke*.yaml` (local), `test_seeds.yaml` (**frozen**) |
| `docs/derivations.md` | every equation behind the code, to re-derive by hand |
| `docs/kaggle_runbook.md` | step-by-step Kaggle instructions |
| `logs/` | research log (ISEF logbook) and AI-use log |

## Quick start (local)

```bash
bash scripts/setup_local_env.sh               # Miniforge + env in ./.env
source .env/miniforge3/bin/activate .env/gdr4
pytest -q
```

Then follow `docs/kaggle_runbook.md`.
